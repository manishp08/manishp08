## Featured project

**[Corridor-Courier-Bot](https://github.com/manishp08/Corridor-Courier-Bot)**: how much does adding camera perception and IMU fusion improve indoor navigation safety over a LiDAR-only Nav2 stack? I answer it with a 1,200-episode paired-seed ablation (DWB and MPPI controllers), a C++ Nav2 costmap layer, and an EKF drift study. Results come from a 2D surrogate simulator, and the repo includes the Gazebo harness and states its limits. Stack: ROS 2, Nav2, C++, Python.

More projects are being cleaned up before I publish them.
